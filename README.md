# World Bridge Consultancy 🌍 — Study Abroad Website

A professional multi-page consultancy website for students looking to study abroad.

## Features
- 🌐 Destinations page covering USA, UK, Canada, Australia, Germany
- 📋 4-step process section explaining the consultancy journey
- ⭐ Student success stories and testimonials
- 📬 Contact form for booking free consultations

## Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript
- **Deployment:** Netlify
